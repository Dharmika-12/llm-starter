# Gemini LLM Starter Project

A simple Python project that connects to Google's Gemini AI API and generates AI responses.

## Technologies
- Python
- Google Gemini API
- `google-genai`
- `python-dotenv`

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/Dharmika-12/llm-starter.git
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Create a `.env` file and add your Gemini API key:
   ```env
   GEMINI_API_KEY=your_api_key
   ```

4. Run the project:
   ```bash
   python hello_llm.py
   ```
